CONNECTION

连接设置

官方标准配置

DeepSeek Harness Web 默认监听 127.0.0.1:3080，OpenSSH 默认端口为 22。SSH 模式会自动把远端 3080 端口转发到本机 3080 端口； 服务器或 ~/.ssh/config 主机别名仍需按实际部署填写。
